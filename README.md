# Character Dossier Builder — Scaffold

Minimal scaffold for the Character Dossier Builder (hand-off implementation).

Features included in this scaffold:
- Vite + React + TypeScript
- Tailwind CSS
- Dexie.js database schema
- Basic layout components (Sidebar + main area)

Quick start

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Preview production build locally:

```bash
npm run preview
```

Deploy to GitHub Pages (requires `gh-pages` and a repo remote):

```bash
npm run build
npm run deploy
```
